Bootstrap (index.php)

The entry point runs a deterministic sequence of steps before handing control to the router:

  1. Defines SYSTEM_PATH and SITE_PATH constants.
  2. Loads vendor/autoload.php if Composer is installed.
  3. Manually require_onces the 22 core classes from system/core/ plus the helper file.
  4. Registers aurora_autoload() — a custom PSR-4-flavoured autoloader.
  5. Calls AuraCore\ErrorHandler::register(true) — wires PHP error/exception/shutdown handlers.
  6. Loads .env via AuraCore\DotEnv::load().
  7. Parses $_SERVER['REQUEST_URI'], trimming slashes.
  8. If the URI starts with /management, hands off to AuraCore\Management::run().
  9. Otherwise requires system/config/routes.php and calls $router->dispatch().
  10. On 404, returns JSON for AJAX requests, otherwise renders site/views/404.php or a built-in dark 404 page.

Autoloader

AuraPHP registers a custom autoloader (aurora_autoload) that maps namespaces to directories and is case-flexible — it tries PascalCase, lowercase, snake_case, and kebab-case filename variants for the requested class, so a class User_Model can live in user-model.php, user_model.php, User_Model.php, or user.php.

Service Container / DI

AuraCore\Container is a small but powerful IoC container with reflection-based auto-wiring.

bind($abstract, $concrete = null) Register a binding. If $concrete is a closure it's invoked on each make(); otherwise the class is auto-built. singleton($abstract, $concrete = null) Same as bind() but the result is cached. instance($abstract, $instance) Register an existing object instance. make($abstract) Resolve a binding (singleton-aware). call($callable, $parameters = []) Reflection-based method invoker. Resolves typed parameters from the container. Accepts 'Class@method' strings. build($class) Reflects the constructor, resolves typed dependencies, instantiates the class.

Service Providers

Providers live in site/providers/, namespace SiteProviders\, and implement:

namespace SiteProviders;

use AuraCore\Container;

class AppServiceProvider
{
    public function register(Container $c): void
    {
        $c->singleton('mailer', function () {
            return new Mailer(config('mail.from'));
        });
    }

    public function boot(): void
    {
        // post-resolution hooks
    }
}

DotEnv

AuraCore\DotEnv is a hand-rolled .env parser — no Composer dependency.

  • Supports KEY=VALUE lines, quoted values, and ${OTHER_VAR} interpolation.
  • Comments start with #.
  • DotEnv::env($key, $default = null) type-casts true/false/null/empty strings and reads from $_ENV first, then getenv().
APP_KEY=0123456789abcdef0123456789abcdef
APP_DEBUG=true
DB_HOST=127.0.0.1
DB_NAME="${APP_NAME}_production"

Logger

Daily rotating log files at storage/logs/YYYY-MM-DD.log.

  • Levels: DEBUG, INFO, NOTICE, WARNING, ERROR, CRITICAL.
  • Configurable minimum level filter.
  • Line format: [<date>] <LEVEL>: <message> <json-context>.
$this->logger()->info('User logged in', ['user_id' => $id]);
$this->logger('payments')->error('Charge failed', ['order' => $orderId]);

Error Handler

AuraCore\ErrorHandler::register($debug = true) wires set_error_handler, set_exception_handler, and a shutdown function.

  • Debug on ($debug = true): renders a dark-themed HTML page with the error class, message, file/line, source code snippet, formatted stack trace, and argument display. CLI gets ANSI-coloured output instead.
  • Debug off: a minimal "500 Internal Server Error" message.
