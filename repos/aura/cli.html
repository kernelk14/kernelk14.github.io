CLI Tool

The aura executable is a single-file PHP CLI (shebang #!/usr/bin/env php) — no Composer required. ANSI-coloured output via custom write() / writeln() helpers.

Commands are dispatched via a big switch statement at the bottom of the file. Three constants are defined up-front: AURA_ROOT, AURA_SYSTEM, AURA_SITE.

Composer integration

With Composer installed, the script is registered as a bin entry, and these scripts are exposed:

composer serve          # → php bin/aura serve
composer route:list     # → php bin/aura route:list

Generators (make:*)

Each make: command writes a stub file into the right directory with the correct namespace. Most accept --force to overwrite an existing file.

Example: make:controller UserProfile --resource

namespace SiteControllers;

use AuraCore\Controller;

class UserProfile extends Controller
{
    public function index()   { /* list */ }
    public function create()  { /* form */ }
    public function store()   { /* POST */ }
    public function show($id){ /* detail */ }
    public function edit($id) { /* edit form */ }
    public function update($id){ /* PUT/PATCH */ }
    public function destroy($id){ /* DELETE */ }
}

Smart migration generator

The CLI recognises common naming patterns and emits a matching skeleton:

  • create_users_table → Schema::create('users', ...)
  • add_email_to_users_table → Schema::table('users', ...)
  • drop_users_table → Schema::drop('users')
