Configuration Reference

system/config/config.php

return [
    'base_url' => // auto-detected from $_SERVER HTTPS + HTTP_HOST,
    // arbitrary dot-accessible keys
];

Accessed via $this->config('base_url') or $this->config('database.default') from any controller.

system/config/database.php

return [
    'default' => [
        'driver'   => 'mysql',
        'host'     => '127.0.0.1',
        'port'     => 3306,
        'username' => 'root',
        'password' => '',

Supports multiple connection groups — load any with $this->loadDatabase('analytics'). Connection merging happens in Base::config().

Environment Variables

Loaded automatically from .env at the project root. php aura key:generate creates the file from .env.example if it doesn't exist.

VariableDescription
APP_KEY32-byte hex secret. Required for any signed/session-based feature.
APP_DEBUGtrue/false — controls the error handler's verbose mode.
Custom variables are read via DotEnv::env('YOUR_KEY', $default) or getenv('YOUR_KEY'). They're available in $_ENV as well.
