Database · Query Builder · Schema Builder

Database

AuraCore\Database is a thin PDO wrapper. It supports MySQL, PostgreSQL, SQLite, and SQL Server. The string mysqli is silently normalized to PDO mysql.

Drivers

Driver stringPDO DSN
mysql / mysqlimysql:host=...;port=...;dbname=...;charset=...
pgsqlpgsql:host=...;port=...;dbname=...
sqlitesqlite:<path-to-file>
sqlsrvsqlsrv:Server=...;Database=...

Connection settings

PDO::ATTR_ERRMODE = EXCEPTION, PDO::ATTR_DEFAULT_FETCH_MODE = FETCH_ASSOC, and native prepared statements are enabled by default.

Direct queries (from README)

$db = $this->loadDatabase();        // 'default' group
$db = $this->loadDatabase('analytics');  // named group

$db->get('users');                              // all rows
$db->getWhere('users', ['id' => 1]);         // WHERE
$db->insert('users', ['name' => 'Alice', 'email' => 'a@b.com']);
$db->update('users', ['name' => 'Bob'], ['id' => 1]);
$db->delete('users', ['id' => 1]);
$db->query('SELECT * FROM users WHERE active = 1');

Transactions

$db->beginTransaction();
try {
    $db->insert('orders', [...]);
    $db->update('inventory', [...], [...]);
    $db->commit();
} catch (\Throwable $e) {
    $db->rollBack();
    throw $e;
}

Query Builder

AuraCore\QueryBuilder is the Eloquent-style fluent query API. Every method returns $this so calls can be chained.

Wheres

where($col, $op = null, $val = null) Two-arg form: where('active', 1). Three-arg form: where('age', '>=', 18). orWhere($col, $op, $val) OR branch. whereIn($col, $array) ... IN (?, ?, ?). whereNull($col) ... IS NULL. whereNotNull($col) ... IS NOT NULL.

Joins & ordering

join($table, $first, $op, $second, $type = 'INNER') leftJoin(...) / rightJoin(...) orderBy($col, $direction = 'ASC') groupBy(...$cols) having($col, $op, $val) limit($n) / take($n) offset($n) / skip($n)

Reads

first() First row, or null. find($id) By primary key. get() Array of rows (associative arrays or hydrated Model instances when a model class is bound). count() Total matching rows. sum($col) / avg($col) / min($col) / max($col) exists() / doesntExist() paginate($perPage = 15, $page = null) Returns a Pagination object.

Writes

insert($data) Single row insert. insertBatch($rows) Bulk insert. update($data) Bulk update matching rows. delete() Delete matching rows. truncate() Truncate the table.

Eager loading & ActiveRecord hooks

with(...$relations) Eager-load relations (hasMany, hasOne, belongsTo). eagerLoads([...]) Same, in array form. setModel($class) Hydrate results into the given Model subclass. setPrimaryKey('id') Custom PK name. toSql() / getBindings() Debug helpers. newQuery() Return a fresh query builder for the same table.

Lazy model hydration sets setRawAttributes() and $exists = true on each instance. Eager loading is batched via whereIn to avoid N+1.

Schema Builder

AuraCore\Schema is a Laravel-style schema builder. Two static entry points:

use AuraCore\Schema;

Schema::create('users', function ($table) {
    $table->increments('id');
    $table->string('name');
    $table->string('email')->unique();
    $table->timestamp('email_verified_at')->nullable();
    $table->string('password');
    $table->timestamps();
});

Schema::table('users', function ($table) {
    $table->string('avatar')->nullable(); // emits ALTER TABLE
});

Schema::drop('users');
Schema::dropIfExists('users');
Schema::hasTable('users');
Schema::hasColumn('users', 'email');

Foreign keys

$table->foreign('user_id')
      ->references('id')
      ->on('users')
      ->onDelete('cascade')
      ->onUpdate('cascade')
      ->name('fk_user_id');

Defaults: engine InnoDB, charset utf8, collation utf8_unicode_ci.
