Installation · Quick Start — Hello World in 60 seconds · Directory Structure · Namespaces · Server Configuration

Installation

Create a new project using Composer (the recommended path), or clone the repository directly if you prefer to live on the bleeding edge.

Option A — Composer create-project

composer create-project kernelk14/aura my-app
cd my-app
php aura serve          # → http://127.0.0.1:8080

Option B — Manual clone

git clone https://github.com/kernelk14/aura.git my-app
cd my-app
php aura key:generate   # writes APP_KEY to .env
php aura serve

What key:generate does

  • Generates a 32-byte hex secret (APP_KEY) and writes it to .env.
  • Auto-creates .env from .env.example if missing.
  • Prints a friendly "next steps" banner.
Tip: AuraPHP has no runtime Composer dependencies. The framework require_onces its own 22 core files and uses a custom spl_autoload_register. Composer is purely a convenience for PSR-4 autoloading.

Quick Start — Hello World in 60 seconds

AuraPHP follows the "convention over configuration" mantra. Three files and you're done:

1. Define a route

Open system/config/routes.php and add:

$router->get('hello', 'hello@index');

2. Create a controller

Create site/controllers/hello.php:

namespace SiteControllers;

use AuraCore\Controller;

class Hello extends Controller
{
    public function index()
    {
        $this->loadView('hello', ['title' => 'Hello World']);
    }
}

3. Create a view

Create site/views/hello.php:

<div class="container mt-5 text-center">
    <h1 class="text-gradient-success"><?= htmlspecialchars($title) ?></h1>
    <p class="text-muted">Built with AuraPHP &hearts;</p>
</div>

That's it. Hit http://127.0.0.1:8080/hello and you'll see your page rendered inside the standard layout (with OwnStrap CSS, navbar, and theme toggle).

Directory Structure

AuraPHP ships as a small, flat project. The directories you actually edit are site/ and system/config/; the rest of system/ is the framework core.

auraphp/
├── aura                        # CLI executable (1,842-line single-file PHP)
├── index.php                  # Front controller / entry point (161 lines)
├── composer.json             # PSR-4 autoload + bin + scripts
├── package.json              # Frontend tooling metadata
├── package-lock.json         # Locked dependency tree
├── .htaccess                 # Apache rewrite → index.php
├── .gitignore                # Ignores node_modules, .env, *.log, .crush
├── public/                    # Web-accessible assets (CSS/JS/fonts)
│   ├── css/
│   │   ├── ownstrap.css          # Main CSS framework (3,443 lines, ~85 KB)
│   │   ├── ownstrap-colors.css   # Color palette (674 lines)
│   │   └── fonts/
│   │       ├── Fira_Sans/          # Fira Sans — 18 files / 9 MB (sans + serif + mono)
│   │       ├── Inter/              # Inter — 58 files / 20 MB (variable + 17 static weights)
│   │       └── JetBrainsMono/      # JetBrains Mono Nerd Font — 4 files / 10 MB
│   └── js/
│       └── ownstrap.js           # OwnStrap JS class (1,152 lines, ~28 KB)
├── system/                    # Framework core (don't edit)
│   ├── core/                    # 25 AuraCore\ classes
│   ├── config/                  # App config (edit these)
│   │   ├── config.php           # App config (base_url, etc.)
│   │   ├── database.php         # Multi-connection DB config
│   │   └── routes.php           # Route definitions
│   ├── helpers/
│   │   └── url_helper.php       # Global functions (autoloaded)
│   └── installer-needs/
│       └── PostInstall.php      # Composer post-install hook
├── site/                      # Your application (M, V, C — edit freely)
│   ├── controllers/            # SiteControllers\  (welcome.php, etc.)
│   ├── models/                 # SiteModels\  (user_model.php, etc.)
│   ├── views/                  # Plain PHP templates
│   ├── templates/              # Reusable partials (navbar, sidebar, etc.)
│   ├── events/                 # SiteEvents\  (event classes)
│   ├── listeners/              # SiteListeners\  (event handlers)
│   ├── middleware/             # SiteMiddleware\  (request middleware)
│   ├── requests/               # SiteRequests\  (form-request validators)
│   ├── rules/                  # SiteRules\  (custom validation rules)
│   ├── scopes/                 # SiteScopes\  (model global scopes)
│   ├── commands/               # SiteCommands\  (custom CLI commands)
│   ├── providers/              # SiteProviders\  (service providers)
│   └── pages/management/        # Built-in admin UI (8 pages: dashboard, database, env, info, logs, migrations, routes, seeders)
└── storage/
    └── logs/                   # Logger writes YYYY-MM-DD.log files (auto-created)
Repo files not part of the framework: the root also contains README.md, README_OWNSTRAP.md, OWNSTRAP_FEATURES.md, OWNSTRAP_QUICKREF.md, and OWNSTRAP_SETUP.md (dev documentation), a hidden .crush/ cache, and any maintainer-only tooling. None of these are loaded by the framework at runtime — they are references for whoever maintains the project.

Server Configuration

Apache (shipped .htaccess)

RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ index.php/$1 [L]

Nginx

server {
    listen 80;
    server_name my-app.local;
    root /var/www/my-app;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$args;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.1-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }
}

PHP built-in server (development)

php aura serve                              # default 127.0.0.1:8080
php aura serve --host=0.0.0.0 --port=3000   # custom host/port

Requirements

  • PHP ≥ 7.4 (with PDO + your DB driver: pdo_mysql, pdo_pgsql, pdo_sqlite, pdo_sqlsrv)
  • Apache with mod_rewrite, or Nginx + PHP-FPM, or PHP built-in server
  • Composer is optional (only used for autoloading convenience)
