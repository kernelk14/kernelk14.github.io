Request · Response · Session · Events & Listeners

Request

AuraCore\Request wraps $_GET, $_POST, $_SERVER, $_FILES, $_COOKIE, and the JSON body.

input($key, $default) Get an input value (any source). all() Get all input as an array. only([$keys]) Whitelist a subset of input. except([$keys]) Blacklist a subset of input. has($key) Whether the key is present and non-empty. method() HTTP method (uppercase). path() URL path component. url() Full URL. ip() Client IP. userAgent() User-Agent string. ajax() Whether the request is XHR. isMethod($m) Match the HTTP method. isGet() / isPost() / isJson() Common-method helpers. file($key) Get a single uploaded file. hasFile($key) Whether a file was uploaded. __get / __isset Magic proxies to input / has.

Response

AuraCore\Response is a fluent response builder.

status($code) Set the HTTP status code. header($k, $v) Add a response header. body($content) Set the response body. json($data, $status = 200) Emit a JSON response. redirect($url, $status = 302) Send a redirect. back() Redirect to the referer. with($key, $value) Flash a value to the session. withInput() Flash all POST input. send() Send headers and body. Response::jsonResponse($data, $status) Static helper.

Session

AuraCore\Session auto-starts the PHP session and exposes a tiny CRUD + flash API.

get($key, $default = null) Read a value. set($key, $value) Write a value. has($key) Existence check. remove($key) Delete a value. all() Full session array. destroy() Destroy the session. regenerate() Regenerate the session ID (anti-fixation). flash($key, $value) Set or read-and-delete a flash value. flashInput($key) Flash form input. hasFlash($key) Check for a flash key. keep([$keys]) Keep flash values for an extra request. reflash() Keep all current flash values.

Events & Listeners

AuraCore\Event is a static dispatcher (Laravel-style).

use AuraCore\Event;

// Listen (string class name is auto-instantiated)
Event::listen('UserRegistered', 'SiteListeners\SendWelcomeEmail');

// Dispatch
$event = new \SiteEvents\UserRegistered($user);
Event::dispatch('UserRegistered', $event);

Events live in site/events/ (SiteEvents\); listeners in site/listeners/ (SiteListeners\) implement handle($event). Also available: removeListener(), getListeners(), flush().
