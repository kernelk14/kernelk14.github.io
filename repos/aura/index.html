Introduction

AuraPHP is a lightweight, convention-driven PHP framework designed to feel familiar to anyone who has used Laravel, while keeping its surface area small and runtime dependencies at zero. It bundles an opinionated CSS/JS toolkit called OwnStrap so you can ship polished UIs without a bundler or a CDN.

What you get out of the box

Front controller

A single index.php with a rewrite-friendly .htaccess and a fallback nginx snippet.

ActiveRecord Models

Eloquent-style models with relations, casts, scopes, soft deletes, and eager loading.

Query Builder

Fluent SQL with parameter binding, joins, aggregates, and pagination.

Schema & Migrations

Laravel-style Blueprint columns, foreign keys, indexes, and a tracked migrations table.

Middleware

Composable handle($req, $next) pipeline — global or per-route.

Auth + Validation

Session-based auth, 16+ built-in validation rules, custom rules, and form-request classes.

Events & Listeners

Static dispatcher for decoupled side-effects.

Service Container

Reflection-based DI with bindings, singletons, instances, and auto-wiring.

CLI Tool

29 commands including serve, migrate, make:*, and more.

Management Panel

8-page admin UI for DB, migrations, routes, logs, env, and PHP info.

OwnStrap CSS/JS

300+ utility classes, 10+ interactive components, dark/light themes.

Logger + Errors

Daily rotating log files and a dark-themed HTML debug page for exceptions.
