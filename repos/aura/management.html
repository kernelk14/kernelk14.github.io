Management Panel

Management Panel

Mounted at /management/*. The panel is intercepted in index.php before routing, and it ships with its own dark layout, sidebar, and Chart.js (loaded from jsDelivr — the only external CDN dependency in the project).

Pages

PathPageWhat it shows
/management/dashboardDashboardTable count, row count, DB size, PHP memory; Chart.js pie (size dist) + bar (rows/table); system resources (memory, disk, CPU); application overview; full table list
/management/databaseDatabaseTable list with engine/rows/size; per-table browser (columns + first 100 rows); SQL Query runner (handles SELECT/SHOW/DESCRIBE/EXPLAIN/INSERT/UPDATE/DELETE)
/management/migrationsMigrationsList of site/migrations/*.php with ran/pending status, batch #, executed_at; buttons to Run / Rollback / Reset
/management/seedersSeedersList of site/seeders/*.php; "Run All Seeders" button
/management/routesRoutesRegex-extracted route list from system/config/routes.php
/management/logsLogsstorage/logs/*.log browser; clear-log button
/management/envEnvironment.env file viewer + runtime $_ENV
/management/infoPHP Infophpinfo() output, theme-styled
Known issue: The migrations page calls Migration::resolveClass($base, $filename), but that static method is not actually defined in the shipped system/core/migration.php. The CLI's migration_class() helper performs the resolution instead. The web UI may fail until that method is added.
