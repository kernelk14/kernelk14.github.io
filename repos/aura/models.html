ActiveRecord Model

AuraCore\Model provides Eloquent-style persistence on top of the QueryBuilder.

Properties

PropertyPurpose
$attributesCurrent values (mutable).
$originalValues as loaded from the DB (used for isDirty()).
$fillableWhitelist of mass-assignable attributes.
$guarded = ['id']Blacklist of protected attributes.
$hiddenAttributes excluded from toArray() / toJson().
$castsType-casting map.
$tableAuto-derived from the class name as snake_case + s.
$primaryKey = 'id'Primary key column.
$incrementing = trueWhether the PK is auto-incremented.
$timestamps = trueAuto-manage created_at/updated_at.
$existsWhether the row is persisted.

Supported $casts types

int, integer, real, float, double, string, bool, boolean, array, json, object, date.

Example

use AuraCore\Model;

class UserModel extends Model
{
    protected $fillable = ['name', 'email', 'password'];
    protected $hidden   = ['password'];
    protected $casts    = ['id' => 'int', 'is_active' => 'bool'];
}

Static query helpers

Model::find($id) Find by primary key. Model::findMany([$ids]) Find many by primary key. Model::all() All rows. Model::where(...) Query builder entry point. Model::count() Count rows. Model::create([$attrs]) Mass-assign + save. Model::firstOrCreate([$attrs], [$values]) Model::firstOrNew([$attrs], [$values]) Model::updateOrCreate([$attrs], [$values]) Model::pluck($col, $key) Array of values (keyed optionally). Model::each(callable) Iterate all rows. Model::chunk($size, callable) Process in batches. Model::with(...$relations) Eager-load relations.

Instance methods

fill($attrs) / forceFill($attrs) Mass-assign (guarded / unguarded). setAttribute($k, $v) / getAttribute($k) __get / __set / __isset Magic access to attributes. toArray() / toJson() Serialize (auto-recursive on relations). setRawAttributes($attrs) Replace $attributes & $original. getOriginal($key = null) isDirty($key = null) / isClean(...) sync() Mark as clean. save() INSERT or UPDATE; manages created_at/updated_at. delete() Delete the row (soft if SoftDeletes is used). destroy($ids) Static batch delete. getKey() / getTable() / getForeignKey() refresh() / fresh() Reload from the database.

Table-name convention: UserModel → user_models; foreign key is usermodel_id. Override via $table.

Boot lifecycle

protected function boot() runs once per class. The framework iterates class_uses_recursive($class) and calls boot<Trait>() for each (e.g. bootSoftDeletes).

Relations

Each relation method stores its metadata via debug_backtrace so the QueryBuilder can eager-load them later.

hasMany($related, $fk, $localKey) belongsTo($related, $fk, $ownerKey) hasOne($related, $fk, $localKey) belongsToMany($related, $table, $fkp, $rkp) 
class UserModel extends Model
{
    public function posts()
    {
        return $this->hasMany(PostModel::class, 'user_id', 'id');
    }
}

class PostModel extends Model
{
    public function author()
    {
        return $this->belongsTo(UserModel::class, 'user_id', 'id');
    }
}

// Lazy load:
$user  = UserModel::find(1);
$posts = $user->posts;        // magic getter triggers the relation
$user->load('posts');  // explicit eager load

Global Scopes

use AuraCore\Model;

class PostModel extends Model
{
    protected static function boot()
    {
        parent::boot();
        static::addGlobalScope(function ($builder) {
            $builder->where('published', 1);
        });
    }
}

// Bypass scopes:
PostModel::withoutGlobalScopes()->get();
PostModel::newQueryWithoutScopes()->get();

Soft Deletes

The SoftDeletes trait adds a deleted_at global scope so Model::all() returns only non-trashed rows.

use AuraCore\Model;
use AuraCore\SoftDeletes;

class PostModel extends Model
{
    use SoftDeletes;
}

$post->delete();          // soft — sets deleted_at
$post->forceDelete();    // hard — DELETE FROM
$post->restore();        // sets deleted_at = NULL
$post->trashed();        // bool

PostModel::withTrashed()->get();   // include soft-deleted
PostModel::onlyTrashed()->get();   // only soft-deleted

Eager Loading

Eager loading batches whereIn queries to avoid the N+1 problem. Use it on the QueryBuilder or directly on a model.

// On the QueryBuilder
$users = UserModel::with('posts')->get();

// Multiple relations
$users = UserModel::with(['posts', 'comments'])->get();

// Lazy-load on an existing instance
$user->load('posts');
