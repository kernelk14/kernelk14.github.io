OwnStrap CSS

OwnStrap is a zero-dependency CSS/JS framework bundled with AuraPHP. It's a custom alternative to Bootstrap with 300+ utility classes and 10+ interactive components, delivered as plain files (no build step).

Files (relative to public/)

  • css/ownstrap.css — 3,443 lines (main)
  • css/ownstrap-colors.css — 674 lines (color palette)
  • js/ownstrap.js — 1,152 lines (class OwnStrap, instantiated as const OS = new OwnStrap();)
  • css/fonts/Fira_Sans/ — 17 weights of Fira Sans
  • css/fonts/Inter/ — Inter variable + static

Integration in any view

<head>
    <?php ownstrap_css(); // emits 2 <link> tags ?>
</head>
<body>
    <!-- content -->
    <?php ownstrap_js(); // emits <script> for public/js/ownstrap.js ?>
</body>

Usage: .text-{color}, .bg-{color}, .bg-gradient-{color}, .text-gradient-{color}, .border-{color}, .btn-{color}, .btn-outline-{color}, .badge-{color}, .alert-{color}.

Components

  • Static (CSS-only): Buttons (6 variants × 3 sizes + outline), Cards, Badges, Alerts, Progress bars, Spinners, Pagination, Breadcrumbs, Tables, List groups, Navbar, Shadows, Forms (with .state-valid/.state-invalid states).
  • Interactive (require ownstrap.js): Modals (with focus trap), Toasts, Tabs (Arrow-Left/Right navigation), Accordion (Enter/Space), Dropdowns (aria-expanded), Collapse, Carousel (auto-play, pause on hover), Tooltips (via data-tooltip), Spinners.

Grid

12-column flexbox grid — .container (max 1200px) / .container-fluid, .row, .col / .col-1...col-12 / .col-sm/md/lg/xl-* / .col-auto.

Spacing scale

m/p-0 to m/p-5 (0, 0.5, 1, 1.5, 2, 2.5rem) plus directional variants (mt-, mb-, ms-, me-, mx-, my-, pt-, pb-, ps-, pe-, px-, py-) and .gap-1..4.

Typography

Font sizes .text-xs/sm/base/lg/xl/2xl/3xl/4xl, weights .fw-light/normal/semibold/bold/bolder, alignment, transform, .text-truncate, .font-monospace.

Utilities

.w-25/50/75/100/auto, .h-25/50/75/100/auto, .min-h-screen, .h-minus-top-5 (calc(100vh - 5rem) — handy for sidebar-below-navbar), .mw-100, .vw-100, .min-vw-100, .backdrop-blur, .bg-glass, .bg-subtle, .bg-card.

Accessibility built-in

  • Focus trap in modals (Tab/Shift-Tab)
  • Arrow-key navigation for tabs, Enter/Space for accordions
  • aria-expanded / aria-haspopup dynamically set
  • :focus-visible outlines on all focusables
  • prefers-reduced-motion disables animations
  • .visually-hidden and .visually-hidden-focusable for SR-only
  • Print styles hide navbar, expand link URLs, remove card shadows

OwnStrap JS — OS global

The OwnStrap JS class is instantiated as a global constant OS on line 1147 of ownstrap.js.

Component APIs

// Modals
OS.openModal(id);
OS.closeModal(id);
OS.toggleModal(id);

// Toasts
OS.success(msg); OS.warning(msg); OS.error(msg); OS.info(msg);
OS.purple(msg);  OS.pink(msg);   OS.cyan(msg);
OS.showToast(msg, type, ms);

// Tabs  – use <button data-tab="tab1">  →  OS.switchTab()
OS.switchTab(tabsContainerId, tabId);

// Accordion
OS.toggleAccordionItem(id);

// Collapse
OS.toggleCollapse(id);   // <button data-toggle="collapse" data-target="id">

// Dropdown
OS.toggleDropdown(id);

// Carousel
OS.nextCarousel(id);
OS.prevCarousel(id);
OS.showCarouselItem(id, index);

// Tooltips  – use <button data-tooltip="..."> (auto-init)

// Progress
OS.setProgress(barId, pct);
OS.animateProgress(barId, from, to, ms);

// Spinners
OS.showSpinner(targetId);
OS.hideSpinner(targetId);

// Forms
OS.validateForm(formId);
OS.clearForm(formId);
OS.getFormData(formId);

// HTTP
OS.get(url);
OS.post(url, data);
OS.put(url, data);
OS.del(url);

// Storage / Cookies
OS.storage.set(key);   OS.storage.get(key);   OS.storage.remove(key);
OS.cookie.set(name);   OS.cookie.get(name);   OS.cookie.remove(name);

// Utils
OS.copyToClipboard(text);
OS.smoothScroll(targetId);
OS.debounce(fn, ms);
OS.throttle(fn, ms);

Theming

Add class="theme-light" or class="theme-dark" on <body> or any container to switch the palette. A theme toggle is included in the default layout (button with id="themeToggle") that persists the choice in localStorage.

The management panel ships dark by default and has its own theme toggle (independent of the main app's theme-dark / theme-light toggle).
