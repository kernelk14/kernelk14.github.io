Routing · Controllers · The

Routing

Routes are defined in system/config/routes.php. The file must return $router.

HTTP method helpers

$router->get($path, $handler) Match GET requests only. $router->post($path, $handler) Match POST requests only. $router->put($path, $handler) Match PUT requests only. $router->delete($path, $handler) Match DELETE requests only. $router->any($path, $handler) Match all four methods above. $router->match([$methods], $path, $handler) Match a custom array of methods.

Handlers

Two formats are supported:

  • String: 'controller@method' — loads site/controllers/<file>.php, instantiates \SiteControllers\<Class>, and calls the method. Path segments are passed as positional arguments.
  • Closure: an anonymous function receives the same arguments as controller methods.

Parameters

Use :name in a path; it compiles to the regex (?P<name>[^/]+). The captured values are passed as positional arguments to your controller method.

Route groups & middleware

$router->get('blog/:id/:slug', 'blog@show');
$router->post('contact', 'contact@store');
$router->put('users/:id', 'user@update');
$router->delete('users/:id', 'user@destroy');
$router->any('webhook', 'webhook@handle');

// Middleware on a single route
$router->get('dashboard', 'dashboard@index')->middleware('auth');

// Group with shared prefix, middleware, and namespace
$router->group(['prefix' => 'admin', 'middleware' => ['auth']], function ($r) {
    $r->get('', 'admin@index');
    $r->get('users', 'admin@users');
});
How dispatch works: the URI is parsed from $_SERVER['REQUEST_URI'] and REQUEST_METHOD. Each route's compiled regex is matched with preg_match. Returns false on no match, which triggers the 404 handler. Middleware is executed by a MiddlewarePipeline that nests the destination in a chain of ($request, $next) closures.

Controllers

Controllers live in site/controllers/ under the SiteControllers\ namespace. Filenames are kebab-case; class names are PascalCase. All controllers extend AuraCore\Controller, which in turn extends AuraCore\Base.

Full example

namespace SiteControllers;

use AuraCore\Controller;
use SiteModels\UserModel;

class UserProfile extends Controller
{
    public function index()
    {
        $users = UserModel::all();
        $this->loadView('user-profile', ['title' => 'Users', 'users' => $users]);
    }

    public function show($id)
    {
        $user = UserModel::find($id);
        $this->loadView('user-profile/show', ['title' => $user->name, 'user' => $user]);
    }

    public function store()
    {
        $data = $this->request()->only(['name', 'email']);
        $result = $this->validate($data, [
            'name'  => 'required|min:3',
            'email' => 'required|email|unique:users,email',
        ]);

        if ($result->fails()) {
            return $this->withErrors($result->errors())->back();
        }

        UserModel::create($data);
        $this->redirect('/users');
    }
}

Controller helper methods

$this->loadView($name, $data = [], $useLayout = true) Renders site/views/<name>.php with extracted variables. Pass false as the third argument to render without the standard layout (useful for full-page views). $this->loadModel($name) Instantiates <Ucfirst>($name) from site/models/. $this->loadDatabase($group = 'default') Returns a singleton-cached Database connection from system/config/database.php. $this->redirect($url) Sends a Location header and exits. $this->back() Redirects to $_SERVER['HTTP_REFERER']. $this->config($item, $default = null) Dot-notation access to the merged config (app + database + optional site/config/app.php). $this->request() Lazy AuraCore\Request (injected by the Router). $this->response() Lazy AuraCore\Response. $this->session() AuraCore\Session instance. $this->validate($data, $rules, $messages = []) Builds a Validator and returns the result object (passes(), fails(), errors()). $this->auth($modelClass = null) Returns an AuraCore\Auth helper bound to the given model class. $this->json($data, $status = 200) Static Response::jsonResponse() shortcut. $this->withErrors($errors) Flashes validation errors to the session and returns $this for chaining. $this->container() Lazy AuraCore\Container (DI). $this->logger($channel = 'app') Returns a Logger instance. $this->event() Returns a new Event instance. $this->dotenv() Returns a DotEnv instance.

The Base Class

AuraCore\Base is the parent of every framework class. It exposes the shared "facade-like" accessors used by controllers, models, and the application code.

loadView($view, $data, $useLayout) Render a view, optionally wrapped in system/core/content-wrapper.php. loadModel($model) Return a new model instance. loadDatabase($group) Get a singleton DB connection by group name. redirect($url) Send a redirect header and exit. config($item, $default) Dot-notation config getter. container() Lazy DI container. logger($channel) Logger by channel name. event() Event dispatcher. dotenv() DotEnv reader.
