Views & Templates · Global Helper Functions

Views & Templates

Views are plain PHP files in site/views/. Variables are extracted before inclusion, so any key you pass to loadView() is available as a local variable in the view.

The default layout

system/core/content-wrapper.php wraps every view by default. It outputs the full HTML document, including:

  • <head> with ownstrap_css() emitting two <link> tags.
  • <body class="theme-light"> with the navbar and theme toggle.
  • View content in the body.
  • ownstrap_js() emitting the ownstrap.js <script> tag before </body>.

Skip the layout

Pass false as the third argument to loadView() for full-page views (used by welcome.php and docs.php):

$this->loadView('welcome', $data, false);

Template partials

Reusable partials live in site/templates/. Include them with the global template('name') helper:

<?php template('navbar'); ?>

<div class="container">
    <!-- page content -->
</div>

Available helpers in views

  • ownstrap_css() — emits the two CSS <link> tags.
  • ownstrap_js() — emits the JS <script> tag.
  • site_url('path') — absolute URL helper.
  • base_url('path') — base URL helper.
  • template('name') — include a template partial.

Global Helper Functions

Defined in system/helpers/url_helper.php (auto-loaded).
